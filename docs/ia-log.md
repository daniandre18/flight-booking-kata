## Lecciones

- Las e2e contra la base real y el socket real encontraron lo que los dobles no podían ver
  (B2, C2). Las pruebas unitarias con dobles prueban las reglas; no prueban el cableado de Nest.
- Un valor medido sospechoso (0 ms, 08:59) se investiga antes de documentarlo (C4, C14).
- Las cifras que la IA "anota" (contrastes, tiempos) se recalculan antes de publicarlas (C10).
